# 實機驗證清單（階段 3 → Gate 3）

| 項目 | 內容 |
|---|---|
| 安裝檔 | GitHub Actions 最新成功一次的 `MyIME-ipa-<編號>`（安裝步驟見 [08_安裝與重簽手冊.md](08_安裝與重簽手冊.md)） |
| 裝置 | iPhone（你的 15 Pro Max）與 iPad 各跑一輪；標「iPad」的項目只在 iPad 測 |
| 回報 | 每項填 ✅ / ❌；❌ 請附**螢幕截圖或螢幕錄影**與一句話描述。不用整份填完，先做 A～C，出問題就先回報 |

> 外觀已用模擬器截圖檢查過；這份清單專注在**只有實機才看得出來**的事：能不能開起來、手感、手勢、震動、系統整合。

---

## A. 能開起來（最重要，先做這一段）

| # | 步驟 | 預期 | 結果 |
|---|---|---|---|
| A1 | 覆蓋安裝新版（不用先刪除），打開 MyIME App | App 能啟動，看到 5 個分頁 | ☐ |
| A2 | 「狀態」頁 | 共用容器是綠色；簽章到期日正確 | ☐ |
| A3 | 備忘錄 → 切到 MyIME 鍵盤 | **鍵盤出現**，不是空白、不閃退；上方有候選列、下方有按鍵 | ☐ |
| A4 | 沒匯入碼表時 | 候選列左側顯示「請先在 MyIME App 匯入碼表」 | ☐ |
| A5 | 打幾個字母，點候選列最左邊的字根 | 送出英文字母 | ☐ |

**若 A3 失敗**：請告訴我「空白 / 閃退 / 卡住」哪一種，這通常是 `inputView` 的問題。

## B. 匯入碼表

| # | 步驟 | 預期 | 結果 |
|---|---|---|---|
| B1 | 「碼表」→ 匯入 `.cin` | 顯示「匯入完成」：名稱、候選字數（約 2.6 萬）、字根數 | ☐ |
| B2 | 「狀態」頁 | 碼表一列變綠色，顯示名稱與字數 | ☐ |

## C. 打中文

| # | 步驟 | 預期 | 結果 |
|---|---|---|---|
| C1 | 打一個你熟悉的字根（例如「米」的碼） | 組字區顯示字根；候選列出現候選字，**順序同碼表** | ☐ |
| C2 | 按空白 | 送出第一個候選字 | ☐ |
| C3 | 點候選列的第 2 個字 | 送出該字 | ☐ |
| C4 | 打錯碼（不存在的組合） | 候選列顯示「無此字」；按空白**不送出**；⌫ 可修正 | ☐ |
| C5 | 打日文假名碼（如 `ka,`、`ka.`） | 出現か、カ；連續打 `i,` `o,` `e,` `o,` → いおえお | ☐ |
| C6 | 單獨按 `,` 或 `.`（沒有在組字） | 進入組字（候選為碼表定義的字），不是直接送出標點 | ☐ |
| C7 | 組字到一半，點輸入框別處 | 組字被清掉，不會殘留字根 | ☐ |
| C8 | 組字中按 Return | 送出你打的**英文字母**，不換行 | ☐ |
| C9 | 組字到一半切到別的 App 再回來 | 不殘留舊字根 | ☐ |

## D. 手感（這段只有你的手指能判斷）

| # | 步驟 | 預期 | 結果 |
|---|---|---|---|
| D1 | 用兩根拇指**快打**一句英文 5 次（`the quick brown fox jumps over the lazy dog`） | 不漏字、不亂序 | ☐ |
| D2 | 打字時看按鍵 | 按下有**放大預覽**（iPhone）；最上排與最左右兩側的預覽不被切掉 | ☐ |
| D3 | 按到按鍵之間的縫隙 / 鍵盤邊緣 | 仍會打出最近的那個鍵，不會沒反應 | ☐ |
| D4 | 每按一個鍵 | 有輕微**震動**（需開啟「允許完整取用」）；有按鍵音（系統「鍵盤點按聲」要開） | ☐ |
| D5 | 與原生鍵盤比較按鍵大小、位置、顏色 | 看起來幾乎一樣（有明顯差異請截圖，這就是 #33） | ☐ |
| D6 | 打字的**反應速度** | 沒有可感覺的延遲或卡頓 | ☐ |

## E. 空白鍵與 ⌫ 的手勢

| # | 步驟 | 預期 | 結果 |
|---|---|---|---|
| E1 | **長按**空白鍵不放，再左右滑 | 鍵帽文字消失；游標跟著左右移動 | ☐ |
| E2 | 組字中，在空白鍵上**快速上滑** | 組字內容當英文送出（首字母可能自動大寫） | ☐ |
| E3 | 點一下空白鍵、長按、上滑 | 三種手勢**不會互相誤觸** | ☐ |
| E4 | 長按 ⌫ | 先連續刪字，**約 1 秒後改成一次刪一個詞**；中文只會一字一字刪 | ☐ |
| E5 | 長按字母鍵（英文模式的 e、a、n、o） | 出現替代字元選單（é è ê…）；滑動選取、放開輸入 | ☐ |
| E6 | 長按 `.`、`-`、`$` | 出現 `… · •`、`– —`、`€ £ ¥` | ☐ |

## F. 中英混打

| # | 步驟 | 預期 | 結果 |
|---|---|---|---|
| F1 | 打 `hello`，點候選列**最左邊的字根**（hello） | 送出英文 hello；候選列最後**沒有**英文格 | ☐ |
| F2 | 中文模式按 Shift 再打字母 | 直接輸出**大寫英文**，不進組字 | ☐ |
| F3 | 左下角是**表情鍵**（沒有中／英鍵） | 點了開表情符號頁；表情頁左下「中」回到鍵盤 | ☐ |
| F4 | （已取消英文模式，不用測） | — | ☐ |
| F5 | 雙擊 Shift | 鎖定大寫；再按一次解除 | ☐ |
| F6 | 連按兩下空白 | 英文變「. 」、中文變「。」 | ☐ |
| F7 | 中文模式打 `?` `!` `[` `]` `"` | 變成全形 `？！「」` ；引號成對 | ☐ |
