## 1. 設計原則

1. **引擎與 UI 分離**：所有輸入邏輯放在純 Swift Package `IMECore`，不 import UIKit，可在 Windows 上 `swift build` / `swift test`（NFR-10）。
2. **狀態機是純函式**：`(狀態, 事件) → (新狀態, 動作清單)`，不直接碰 `textDocumentProxy`，所有行為都能用單元測試驗證。
3. **碼表只在裝置上**：碼表由使用者匯入，轉成唯讀索引檔存在 App Group；repo、CI、.ipa 都不含碼表（R-LIU-1）。
4. **隱私預設**：不連網；日誌不記錄輸入文字與剪貼簿內容（NFR-06）。
5. **免費簽章友善**：App Group ID 從描述檔動態讀取（AltStore 會加 Team ID 後綴）；所有使用者資料可匯出 / 匯入。

## 3. IMECore

### 3.1 子模組

| 子模組 | 職責 | 對應需求 |
|---|---|---|
| `Cin` | `.cin` 解析（UTF-8 為主、Big5 備援；註解、空行、容錯） | FR-K01 |
| `Table` | 碼表索引檔的**建立**（匯入時）與**查詢**（鍵盤執行時） | FR-A03, D01, NFR-15 |
| `Composer` | 組字狀態機：字根、候選、錯碼、Return、`'` 同音字模式、中英混打 | FR-K02~K14, E01~E05 |
| `Candidates` | 候選分頁、展開候選表的資料 | FR-K05, K06 |
| `Suggestion` | 常用詞建議（基礎詞庫 + 使用者記錄，不影響碼表順序） | FR-S01~S05 |
| `Phonetic` | 字 → 讀音 → 同音字、反查字根 | FR-S06, S07 |
| `Kana` | 假名查表驗證；（COULD）羅馬字 → 假名備援規則 | FR-J01~J07 |
| `English` | 自動大寫、雙空白句點、Shift / Caps 狀態 | FR-U07~U09 |

### 3.2 組字狀態機

```swift
public enum InputEvent {
    case key(Character)          // 字母、, . ' 等字根鍵
    case shiftedKey(Character)   // Shift + 字母：直輸大寫（FR-E02）
    case space, returnKey, backspace
    case selectCandidate(Int)
    case swipeUpSpace            // 空白鍵上滑：送出英文（FR-E03）
    case contextChanged          // 游標移動、切換欄位、收起鍵盤（FR-K14）
}

public enum OutputAction: Equatable {
    case insert(String)
    case deleteBackward
    case setMarked(String)       // 組字顯示於輸入框模式（FR-K13）
    case clearMarked
}

public struct ComposerState: Equatable {
    public var mode: Mode        // .idle / .composing / .homophone(...)
    public var code: String      // 目前字根（上限 = 碼表最長碼長，實測為 5）
    public var candidates: CandidatePage
    public var englishOption: String?   // 候選列的英文選項（FR-E01）
}

public struct Composer {
    public mutating func handle(_ event: InputEvent) -> [OutputAction]
}
```

- **組字上限**：取自碼表統計的最長碼長（假名碼含 `,` `.` 結尾，實測 5），不寫死 4。
- **錯碼**：查無候選時保留字根並顯示「無此字」，不自動清除（FR-K07）。
- **中英混打**：超過最長碼長或查無候選時不判錯碼，候選列仍提供英文選項（FR-E05）。
- **Return**：組字中送出原始字母，不換行（FR-K12）。

### 3.3 碼表索引格式（決策 ADR-01）

| 選項 | 優點 | 缺點 |
|---|---|---|
| SQLite | 成熟、可 SQL 查詢 | Windows 的 Swift 沒有內建 SQLite 模組，IMECore 測試需另外打包 SQLite |
| **自訂唯讀索引檔（採用）** | 純 Foundation，Windows 可測；以 memory-map 開啟，不做整表預載（NFR-15）；26k 筆約 0.5 MB | 格式需自行定義與版本化 |

**索引檔 `table.idx` 結構**（little-endian）：

```
Header   magic "MYIX" | 格式版本 | 碼表 ename/cname/selkey | 最長碼長 | 筆數
Keys     依「字根」排序的固定長度紀錄：字根(最多 8 bytes) | 候選起始位置 | 候選數
Values   UTF-8 候選字串，依碼表原始順序（FR-K05）
Reverse  字 → 字根清單（反查字根用，FR-S07）
```

- 查詢：二分搜尋 Keys（26k 筆約 15 次比較，遠低於 30 ms，NFR-01）。
- 前綴查詢（候選預覽、萬用字元 FR-K11）同樣用二分搜尋找範圍。
- 匯入時由主 App 建立；**鍵盤只讀**。

使用者資料（常用詞、剪貼簿、設定）量小，以 JSON 檔存放，格式帶版本號以便 migration（FR-D06）。

> 本決策將需求規格書 FR-A03 / FR-D01 中的「轉成 SQLite」改為「轉成唯讀索引檔」，於下次修訂需求規格書時同步。

## 4. 資料與儲存

### 4.1 存放位置

| 資料 | 位置 | 寫入方 | 讀取方 |
|---|---|---|---|
| 碼表索引 `table.idx` | App Group | App（匯入時） | 鍵盤 |
| 碼表索引快取 | 鍵盤自身容器 | 鍵盤（有 Full Access 時從 App Group 複製） | 鍵盤（無 Full Access 時，NFR-07） |
| 設定 `settings.json` | App Group | App | 鍵盤（每次 `viewWillAppear` 重新讀取） |
| 主題 | App Group（自訂）＋ bundle（內建） | App | 鍵盤 |
| 常用詞記錄 | App Group | 鍵盤 | 鍵盤、App（管理頁） |
| 剪貼簿歷史 | App Group | 鍵盤（使用者按下剪貼簿按鈕時，R7） | 鍵盤、App |
| 開源資料（讀音、詞庫） | bundle（唯讀） | — | 鍵盤、App |
| 自動備份 | 「檔案」App 中使用者選定的資料夾 | App | App |

- App Group ID 一律透過 `AppGroupResolver`（讀 `embedded.mobileprovision`），不寫死。
- 鍵盤與 App 不同時寫同一個檔：寫入用「暫存檔 + 原子性取代」。

## 5. 鍵盤擴充

```
KeyboardViewController（UIInputViewController）
  └ KeyboardController        事件協調：觸控 → Composer → OutputAction → textDocumentProxy
      ├ TouchLayer            多指觸控、重疊時提早送出前鍵、縫隙歸屬最近鍵（Spike 0.15 已驗證）
      ├ KeyboardView          依版面 JSON 排列按鍵；主題 token 取色
      ├ CandidateBar          永遠佔位；空狀態顯示常用詞建議或工具按鈕（FR-U21）
      ├ TextOutput            包裝 textDocumentProxy；唯一能改動輸入框的地方
      └ ThemeProvider         載入主題，0.3 秒內套用（NFR-14）
```

- **生命週期**：`viewWillAppear` 讀設定與主題；`textDidChange` / `selectionDidChange` 觸發 `contextChanged` 清除組字（FR-K14）。
- **地球鍵**：`handleInputModeList(from:with:)`，iPad 永遠顯示（Spike 0.14 已驗證）。
- **記憶體**：碼表索引 memory-map、圖片背景限制解碼大小，目標常駐 < 30 MB（NFR-03）。

## 7. 品質、隱私與記錄

- `os.Logger` 只記錄事件與數量（例：`candidates count=3`），**不記錄字根、候選字、輸入文字、剪貼簿內容**。
- 測試只使用虛構碼表 `Fixtures/sample.cin`。
- CI：Linux 跑 IMECore 測試與碼表防護；macOS 編譯、檢查 App Group entitlements、打包 .ipa。
