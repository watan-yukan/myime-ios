# 安裝與重簽手冊

| 項目 | 內容 |
|---|---|
| 對象 | 把 MyIME 裝在自己的 iPhone / iPad 上的使用者（也就是你） |
| 前提 | Windows 電腦、免費 Apple ID、iOS / iPadOS 17 以上 |
| 對應 | [02_開發流程規劃.md](02_開發流程規劃.md) 6.3、Issue #51 |

> **側載工具只用 AltServer / AltStore。** Sideloadly 用免費帳號時不會註冊 App Group，App 與鍵盤無法共用資料（見 [05_Spike驗證手冊.md](05_Spike驗證手冊.md) Gate 0 結論）。兩種工具交替使用還會互相撤銷憑證，造成「無法信任」。

---

## 1. 一次性準備（Windows）

| 工具 | 取得方式 | 備註 |
|---|---|---|
| iTunes、iCloud（Apple 官網版） | `winget install --id Apple.iTunes --exact`、`winget install --id Apple.iCloud --exact`（用系統管理員身分） | **不要裝 Microsoft Store 版** |
| Apple Mobile Device Support | `winget install --id Apple.AppleMobileDeviceSupport --exact` | 讓 Windows 認得 iPhone；iTunes 沒一併裝上時才需要 |
| AltServer | `winget install --id RileyTestut.AltServer --exact` | 裝好後只會出現在右下角系統匣（菱形圖示） |

裝完請**重新開機**一次。

---

## 2. 取得安裝檔

1. 打開 GitHub repo 的 **Actions**，點最新一次成功（綠勾）的 `build`。
2. 頁面最下面 **Artifacts** → 下載 `MyIME-ipa-<編號>`，解壓縮得到 `MyIME.ipa`。
   - 正式版會附在 **Releases**（打 `v*` 標籤時產生）。
3. 安裝檔**不含碼表**；碼表由你在 App 內匯入。

---

## 3. 第一次安裝

1. iPhone / iPad 用 USB 連接電腦，解鎖，出現「要信任這部電腦嗎？」按**信任**。
2. 打開 **AltServer**（右下角菱形圖示）。
3. **只有第一次**需要把 AltStore 裝到手機：點圖示 →「Install AltStore」→ 選你的裝置 → 輸入 Apple ID 與密碼（Apple ID 密碼只在這個視窗輸入）。
4. 裝 MyIME：**按住 Shift**，點 AltServer 圖示 →「Install AltStore」→ 選裝置 → 選 `MyIME.ipa`。
5. 手機上：
   - **開發者模式**：設定 → 隱私權與安全性 → 開發者模式 → 開啟 → 重新開機 → 開機後再按「開啟」。（要先裝過一次 App 才會出現這個選項；iPad 一樣。）
   - **信任**：設定 → 一般 → VPN 與裝置管理 → 你的 Apple ID → 信任。這一步需要網路；遇到「無法信任」請改用行動網路、關掉 VPN。
6. 打開 **MyIME** App，確認能啟動。

> iPhone 與 iPad **各自安裝一次**；免費帳號每台裝置最多同時 3 個側載 App。

---

## 4. 啟用鍵盤

1. 設定 → 一般 → 鍵盤 → 鍵盤 → **新增鍵盤** → MyIME。
2. 點「MyIME」→ 開啟「**允許完整取用**」。（按鍵震動與碼表快取需要；沒開仍可打字。）
3. **保留 Apple 內建鍵盤**，簽章到期時才有備援。
4. 在 MyIME App 的「狀態」頁確認：鍵盤、完整取用、共用容器都是綠色。

## 5. 匯入碼表

1. 把你的 `.cin` 放進「檔案」App 看得到的位置（例如 iCloud Drive；Windows 上可用 iCloud 資料夾）。
2. MyIME App →「碼表」→「從「檔案」匯入 .cin 碼表」→ 選檔。
3. 完成後會顯示名稱、候選字數與字根數。碼表只存在這台裝置上，**不會上傳，也不會放進備份**。
4. 到備忘錄之類的輸入框，按地球鍵切到 MyIME，就能打字。

---

## 6. 每 7 天重簽（免費 Apple ID 的限制）

簽章 7 天到期，到期後 MyIME 打不開、鍵盤失效（Apple 內建鍵盤不受影響）。

**做法：電腦開著 AltServer，手機接 USB，再用相同方式安裝一次同一個 `MyIME.ipa`**（按住 Shift → Install AltStore → 選裝置 → 選 .ipa）。直接覆蓋，不用先刪除。

- 資料（碼表、設定、常用詞）**會保留**：Spike 已驗證覆蓋重裝後共用容器與 App 的資料都在。
- 到期日在 MyIME App「狀態」頁的「簽章到期」；剩 2 天以內會變黃色提醒。
- **不要換 Apple ID、不要改 Bundle ID**，也不要先刪除 App 再裝，否則資料會消失（見下面「還原」）。

---

## 7. 資料保護與還原

| 情境 | 結果 | 怎麼辦 |
|---|---|---|
| 覆蓋重裝（重簽） | 資料保留 | 不用做任何事 |
| 刪除 App 後重裝 / 換 Apple ID | 設定、常用詞、碼表全部消失 | 從備份還原，再重新匯入碼表 |

**建議一次設定好自動備份**：MyIME App →「更多」→「備份與還原」→「選擇資料夾…」（建議選 iCloud Drive 裡的資料夾）→ 開啟「開啟 App 時自動備份」。之後每次打開 App 都會備份，並保留最近 N 份。

**還原**：重裝後到同一頁 →「資料夾內的備份」點最新一份 → 還原。備份**不含碼表**，頁面會提示要重新匯入哪個檔。

## 8. 疑難排解

| 現象 | 原因與做法 |
|---|---|
| Sideloadly / AltServer 找不到裝置 | 沒裝 Apple Mobile Device Support，或 USB 線只能充電。裝好驅動、重新插拔、手機解鎖並按「信任」 |
| AltServer 錯誤 `-80046` | Apple 暫時拒絕這個帳號的請求。關掉 Sideloadly 背景程式、確認 developer.apple.com 沒有待同意的條款、等 30 分鐘再試 |
| 「無法信任開發者」 | 手機連不上 Apple 驗證。改用行動網路、關 VPN；或憑證被另一個工具撤銷：刪除 MyIME 與 AltStore，只用 AltServer 重裝 |
| 狀態頁「共用容器」是紅色 | App Group 沒簽進去：確認是用 AltStore（AltServer）安裝，且 CI 的「App Group entitlements 檢查通過」 |
| 狀態頁「碼表」是紅色 | 還沒匯入，或匯入失敗；到「碼表」頁看錯誤訊息 |
| 鍵盤打不出中文 | 還沒匯入碼表；候選列左側會顯示提示 |
| 按鍵沒有震動 | 沒開「允許完整取用」，或 MyIME 設定頁關閉了震動 |
| App 打不開 | 簽章過期，照第 6 章重簽 |
| 想回到 Apple 內建鍵盤 | 按地球鍵（長按可選鍵盤） |

---

## 9. 安全提醒

- Apple ID 密碼只輸入在 AltServer 的視窗，**不要寫進任何檔案、不要貼給別人或 AI**。
- repo 是公開的：不要把 `.cin` 碼表、`.ipa`、憑證放進去（CI 有碼表防護，會擋下）。
