## 1. 專案背景與目標

### 1.1 背景
- 想要一個依自己習慣客製化的 iOS 嘸蝦米輸入法，外觀與操作手感盡量接近 iOS 內建鍵盤。
- 只在自己的 iPhone / iPad 上使用，不需要上架，也不需要經過 App Review。
- 手邊沒有 Mac，必須以 **Windows + 雲端 macOS 編譯** 的方式完成開發與安裝。

### 1.2 目標
1. 做出可在 iPhone / iPad「設定 → 一般 → 鍵盤」中啟用的第三方鍵盤。
2. 支援**嘸蝦米**中文輸入與英文輸入，可切換。
3. 外觀與常用操作（觸控板移游標、長按替代字元、自動大寫等）比照 iOS 原生鍵盤。
4. 全程在 Windows 上開發，透過雲端 CI 編譯出 `.ipa`，再從 Windows 側載到裝置。
5. 建立可重複的開發 → 編譯 → 安裝流程，日後修改能快速更新到手機上。

### 1.3 非目標（本期不做）
- 不上架 App Store、不做 TestFlight 公開測試。
- 不做雲端同步、帳號系統、使用者行為收集。
- 不做語音輸入、手寫輸入、AI 聯想。
- **不做候選字詞頻學習**：嘸蝦米候選字順序固定，方便記憶與盲打。

## 2. iOS 平台基本限制（需求的前提）

| # | 限制 | 對本專案的影響 |
|---|---|---|
| L1 | 第三方鍵盤必須是 **Keyboard Extension（.appex）**，且需包在一個 **Containing App（主 App）** 裡安裝 | 專案至少有 2 個 Target：主 App + 鍵盤擴充 |
| L2 | 鍵盤擴充有**記憶體上限**（實務上約數十 MB，依機型 / iOS 版本而異，超過會被系統直接終止） | 碼表與詞庫以唯讀索引檔 memory-map 按需查詢，不整包載入；目標常駐記憶體 < 30 MB |
| L3 | 沒有開啟「**完整取用（Full Access）**」時，鍵盤不能連網、**不能存取與主 App 的共用容器**、不能讀取剪貼簿 | 剪貼簿歷史、碼表匯入、設定同步都需要 Full Access（見 4.5） |
| L4 | 密碼欄位、電話撥號鍵盤等**安全輸入欄位**，系統會強制改用內建鍵盤 | 屬正常現象，不列為缺陷 |
| L5 | 必須提供「**切換到下一個鍵盤**（地球鍵）」功能（依 `needsInputModeSwitchKey` 判斷是否顯示） | 鍵盤 UI 必須保留地球鍵位置 |
| L6 | iPad 接**實體鍵盤**時，第三方鍵盤**無法攔截實體按鍵**輸入 | 只支援螢幕鍵盤 |
| L7 | 鍵盤擴充**不能使用麥克風**，也**沒有 API 可呼叫系統聽寫**（iPhone Face ID 機型鍵盤下方的系統麥克風仍可使用，iPad 沒有此列） | 本期不做語音輸入；日後可選「切到內建鍵盤聽寫」或「主 App 背景錄音」方案（見 FR-U17） |
| L8 | 側載 App 必須經過 Apple 簽章；**免費 Apple ID 簽章效期 7 天**、最多 3 個側載 App、每週可註冊的 App ID 數量有限 | 每 7 天需重簽；主 App + 鍵盤擴充會佔用 2 個 App ID |
| L9 | iOS 16 以上須在裝置開啟「**開發者模式**」才能執行側載 App | 安裝手冊需包含此步驟 |
| L10 | 沒有 Mac 就沒有 Xcode、iOS 模擬器、Xcode 除錯器 | 編譯靠雲端 CI，除錯靠日誌 |
| L11 | 鍵盤只能透過 `textDocumentProxy` 操作文字：可左右移動游標，**無法直接上下移動游標**、無法取得整份文件內容 | 觸控板模式只支援左右移動（上下移動以「估算行寬」模擬，列為 COULD） |
| L12 | 鍵盤**只有在畫面上顯示時**才會執行，無法在背景監聽剪貼簿 | 剪貼簿歷史只能記錄「鍵盤開啟期間」看到的剪貼簿內容 |

## 3. 嘸蝦米碼表授權與 Public Repo 的處理（重要）

嘸蝦米輸入法的字根與官方碼表屬於行易有限公司的智慧財產，**不能隨開源程式碼散布**。因為原始碼放在 Public repo，且 Public repo 的 CI 產出物（Artifacts / Releases）任何人都能下載，所以：

| 規則 | 說明 |
|---|---|
| R-LIU-1 | **Repo 與 CI 產出的 `.ipa` 都不得包含嘸蝦米碼表** |
| R-LIU-2 | 碼表由使用者**自行合法取得**（例如自己購買的嘸蝦米授權所附碼表），以 `.cin` 格式在**主 App 中匯入**到裝置上 |
| R-LIU-3 | `.gitignore` 排除 `*.cin`（測試用的虛構小型碼表 `Tests/Fixtures/sample.cin` 除外） |
| R-LIU-4 | 單元測試只使用**虛構的測試碼表**，不使用真實嘸蝦米字根 |
| R-LIU-5 | App 名稱、圖示、Repo 名稱不使用「嘸蝦米」商標字樣，README 中僅描述為「相容 .cin 碼表的形碼輸入法引擎」 |

**引擎設計因此是「通用 .cin 碼表引擎」**，嘸蝦米是載入的其中一份碼表。日後也能換成倉頡、行列等其他碼表。

> 若 Spike 驗證發現免費 Apple ID 無法使用 App Group（無法把匯入的碼表分享給鍵盤），備案見風險 R2。

| FR-U25 | **下滑輸入（iPad、iPhone）**：字母鍵上方以淺灰小字顯示數字 / 符號，往下滑超過約半個鍵高放開即輸入該字元，跨過門檻時震動、放大預覽同步顯示該字元，滑回可取消。對應字元沿用 iPad 原生：`q`～`p` → `1`～`0`、`a`～`l` → `@ # $ & * ( ) ' "`、`z`～`m` → `% - + = / ; :`。組字中下滑出的數字與數字頁相同（選對應候選字），標點依中文模式轉全形。iPhone 原生沒有此功能，為減少切換數字頁而加入；設定頁可關閉（預設開啟），關閉時鍵帽不顯示小字。系統的單手操作（Reachability）只從螢幕最底邊觸發，不影響字母鍵 | SHOULD |
| FR-U26 | **iPhone 字母頁底排 `,` `.` 鍵**：底排改為 `123`、表情、空白、`,`、`.`、Return（逗號、句號緊鄰在空白鍵右邊，比照 iPad 兩鍵相鄰）。`,` 對齊上方 `n`、`.` 對齊 `m`，與字母鍵同寬；Return 使用剩下的寬度（430 pt 寬約 58 pt，與 iOS 26 原生網址鍵盤的 Return 相近），只放圖示（FR-U10）。`,` 下滑輸入 `!`、`.` 下滑輸入 `?`（同 iPad 的 Shift + `,` / `.`）。組字中兩鍵為字根碼（嘸蝦米與日文假名需要），不必切到數字頁。Email、網址欄位的底排版面維持原樣 | MUST |
| FR-U27 | **空白鍵上滑提示**：組字中（已打字根）空白鍵中央顯示淺灰色雙折線圖示（`chevron.up.2`），提示可上滑送出英文（FR-E03）；沒在組字時空白鍵維持空白（同原生）；觸控板模式時隨鍵帽文字一起隱藏；iPhone、iPad 皆有 | SHOULD |

## 6. 開發與部署環境需求（無 Mac 方案）

### 6.1 整體架構

```
[Windows 11 開發機]                [GitHub Actions macOS]         [iPhone / iPad]
 VS Code + Swift for Windows  →   - XcodeGen 產生專案         →   Sideloadly / AltStore
 - 寫程式、跑 IMECore 測試         - xcodebuild 編譯 + UI 測試       - 以免費 Apple ID 簽章安裝
 - git push（Public repo）         - 輸出「未簽章、不含碼表」.ipa     - 每 7 天重簽
                                                                    - 主 App 匯入自己的 .cin 碼表
```

### 6.2 工具清單
| 用途 | 工具 | 備註 |
|---|---|---|
| 編輯器 | VS Code + Swift 擴充套件 | |
| 本機編譯 / 測試核心 | Swift for Windows 工具鏈 | 只能編譯不依賴 UIKit 的程式碼 |
| 版本控制 | Git + GitHub **Public** repo | Public repo 使用標準 GitHub-hosted runner 不計分鐘數 |
| 雲端編譯 | GitHub Actions macOS runner | |
| 專案產生 | XcodeGen | 在 CI 上執行 |
| 安裝到裝置 | **AltStore + AltServer**（Sideloadly 不會註冊 App Group，不採用） | 需安裝 Apple 官網版 iTunes + iCloud（非 Microsoft Store 版） |
| 裝置日誌 | libimobiledevice（`idevicesyslog`）for Windows | 取代 Xcode Console |
| 備援 | 短期租用雲端 Mac | CI 無法解決的除錯問題時使用 |

### 6.3 簽章策略（決定：免費 Apple ID）
- CI 輸出**未簽章** `.ipa`（`CODE_SIGNING_ALLOWED=NO`）。
- Windows 上以 Sideloadly / AltStore 用免費 Apple ID 重簽並安裝，簽章 7 天到期需重簽。
- 若 App Group 在免費帳號下無法使用，或重簽太麻煩，再評估升級付費開發者帳號（US$99 / 年、效期 1 年）。

## 8. 驗收標準（MVP v1.0）

- [ ] 主 App 可透過側載安裝於 iPhone 與 iPad，並能在「設定 → 鍵盤」中新增本鍵盤。
- [ ] 主 App 可匯入 `.cin` 碼表，鍵盤可使用該碼表以嘸蝦米輸入中文。
- [ ] 在備忘錄、LINE、Safari 網址列中可用嘸蝦米打字、選字、輸入標點。
- [ ] 字母 / 數字 / 符號頁可切換，表情鍵開啟表情符號頁；地球鍵點擊切換、長按顯示鍵盤清單（同原生）。
- [ ] iPad 鍵盤上有地球鍵，點擊 / 長按行為與原生相同。
- [ ] 外觀與 iOS 原生鍵盤並排比對無明顯差異（深 / 淺色、iPhone / iPad、直 / 橫向）。
- [ ] 觸控板移游標、長按替代字元、自動大寫、雙空白句點皆可正常使用。
- [ ] 嘸蝦米模式下不切換鍵盤即可輸出英文：候選列英文選項、Shift + 字母大寫、空白鍵上滑（且可於 App 中關閉）。
- [ ] 以 `i,` `o,` `e,` `o,` 可打出「いおえお」、以 `a.` `i.` 打出「アイ」，且不影響一般嘸蝦米中文輸入。
- [ ] 送出字詞後候選列出現常用詞建議。
- [ ] 可在主 App 與鍵盤上切換內建主題，切換後立即套用；所有主題在深 / 淺色下文字清楚可讀。
- [ ] 連續打字 10 分鐘無 crash，記憶體 < 30 MB。
- [ ] 快打多指重疊不掉字；候選列不跳動；冷啟動第一鍵無停頓。
- [ ] 重簽 / 重裝後，可由自動備份一鍵還原設定與常用詞。
- [ ] IMECore 單元測試覆蓋率 ≥ 80%，CI 全綠；repo 與 `.ipa` 中不含任何碼表。
- [ ] 安裝 / 重簽手冊可在 15 分鐘內完成重新安裝。

（剪貼簿歷史、同音字 / 反查字根為 v1.1 驗收項目。）
